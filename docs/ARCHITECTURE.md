## Движок (`src/state/engine.ts`)

Единственный владелец «истины» об исследованном мире. `onFix(fix)`:

1. публикует позицию в UI;
2. отбрасывает сигналы с плохой точностью (порог в настройках);
3. если точка в **исключённой зоне** — ничего не открывает, не считает и **не пишет трек** (и сбрасывает «якорь», чтобы не соединять линией вход и выход из зоны);
4. дрожание GPS (< 3 м) не считается движением; «телепорт» (> 70 м/с или > 8 км за фикс — самолёт) открывает только точку, без линии и дистанции;
5. открывает ячейки вдоль отрезка `prev → cur` (шаг не реже `радиус/2`, чтобы не было дыр);
6. обновляет дневную статистику, трек, счётчики; планирует сохранение (2,5 с дебаунс + при уходе со страницы);
7. пересчитывает статистику → XP → уровень → челленджи; поздравления показываются один раз.

XP — **производная величина**: `baseXp(stats) + награды выполненных челленджей`. Поэтому смена исключённых зон, удаление заметки или импорт копии не ломают учёт.

## Туман

**Данные** (`core/fog.ts`): мир разбит на квадратные ячейки z20 Web Mercator. Ключ ячейки — `x·2²⁰ + y`. Ячейки лежат в чанках 64×64 (`Map<chunkKey, Set<localIndex>>`); в БД сохраняются только изменённые чанки (`Uint16Array`). Площадь считается по широте строки (`cos φ`), поэтому статистика точна на любых широтах.

**Отрисовка** (`map/fog-renderer.ts`) — два канваса поверх MapLibre:

* `fog`: сплошная заливка + «облачная» текстура; открытые области «вырезаются» маской (`destination-out`).
  * Маска строится в половинном разрешении: ближний план — мягкие кисти (по одной на ячейку), дальний — блоки пикселей + размытие; затем пороговая кривая по альфе даёт чёткую, но гладкую границу.
  * Свечение границы: уменьшенная копия маски → окраска в акцентный цвет → `source-atop` только поверх тумана.
  * Проекция ячеек — аффинное преобразование, откалиброванное по `map.project()` (учитывает поворот карты), без вызова MapLibre на каждую ячейку.
* `zone`: исключённые зоны (штриховка, пунктир, подпись) — отдельный канвас, чтобы в режиме «без тумана» зоны оставались видны.

Замеры (headless Chromium, программный рендеринг, 341 тыс. ячеек = 261 км²): z9 — 16 мс, z11 — 8 мс, z13–14 — 2–3 мс, z15 — 7 мс, z16–17 — 3–4 мс. Ключевая оптимизация: кисть и маска — CPU-канвасы (`willReadFrequently`), иначе каждый `drawImage` кисти вызывал чтение с GPU (×15 медленнее).

## Карта

`map/pmtiles.ts` регистрирует протокол `pmtiles://` в MapLibre. Источники: файл из `public/maps` (HTTP Range) или `Blob` из IndexedDB (`FileSource`). Стиль (`map/style.ts`) — слои `@protomaps/basemaps` с доработанной палитрой, глифы и спрайты — абсолютные локальные URL (нужны воркерам). MapLibre 6 требует явного `setWorkerUrl` — подключён через Vite (`?worker&url`).

## Безопасность сети

Три независимых барьера: CSP в `index.html`; отсутствие `INTERNET` на Android; отсутствие внешних ресурсов в коде. Проверка — `scripts/verify-offline.mjs`.
