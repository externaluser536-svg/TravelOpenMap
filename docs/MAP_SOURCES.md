# Источники карт и слоёв

Как устроена подгрузка карт в CoMaps / Organic Maps, чем её можно заменить в веб-приложении и что выбрано в TravelOpenMap.

> Серверы CoMaps, Organic Maps, OpenFreeMap и Protomaps из среды разработки недоступны, поэтому сведения о них — из публичной документации и исходного кода проектов, **сетевое поведение реальных серверов здесь не проверялось**. Всё, что запускалось, работает с подменой серверов (см. [«Что проверено»](#что-проверено)).

## CoMaps и Organic Maps

| Что | Как устроено |
|---|---|
| Формат карт | Собственный бинарный формат **MWM**: по файлу на регион (страна или её часть), содержит векторные объекты, поисковый индекс и данные маршрутов. Читается только их движком отрисовки. |
| Откуда берутся | Файлы генерируются из выгрузки OpenStreetMap собственным конвейером и раздаются с CDN/зеркал проекта; версия карт — дата сборки. Приложение получает список регионов и скачивает нужный файл целиком. |
| Как подгружается | Приложение определяет регион по положению и предлагает скачать его карту; можно выбрать регион вручную. Обновление — той же загрузкой новой версии. |
| Слои | «Метро», «Активный отдых» (туристические и велосипедные маршруты, вершины, стоянки), «Высоты» (изолинии и профиль высот из данных рельефа). Слои — часть стиля их движка и данных в MWM/дополнительных файлах. |

Для веб-приложения на MapLibre MWM непригоден: формат закрытый для сторонних отрисовщиков, а серверы предназначены для их клиентов. Поэтому берётся тот же принцип (скачать область → работать без сети), но на открытых форматах.

## Что использует TravelOpenMap

| Данные | Источник | Формат | Как загружается |
|---|---|---|---|
| Основная карта | [OpenFreeMap](https://openfreemap.org) — бесплатные тайлы всей планеты на данных OpenStreetMap, без ключей | Векторные тайлы схемы OpenMapTiles, TileJSON `https://tiles.openfreemap.org/planet` (до 14 масштаба) | По мере просмотра карты; каждый тайл сохраняется в кэше на устройстве |
| Слой «Метро» | Те же тайлы: `transportation` (`class=transit`, `subclass=subway/light_rail/tram`), `poi` (`class=railway`, `subclass=subway`) | — | Без дополнительной загрузки |
| Слой «Активный отдых» | Те же тайлы: тропы и дорожки (`path`, `track`, `cycleway`, `bridleway`), канатные дороги (`aerialway`), вершины (`mountain_peak`), кемпинги и приюты (`poi`) | — | Без дополнительной загрузки |
| Слой «Высоты» | [AWS Terrain Tiles](https://registry.opendata.aws/terrain-tiles/) (открытый набор, формат Terrarium) | PNG-тайлы, высота кодируется цветом | Тайлы рельефа; изолинии и тени строятся на устройстве (`maplibre-contour`) |
| Область для офлайна | Тот же источник | — | Кнопка «Сохранить для офлайна»: тайлы области скачиваются и закрепляются в кэше |
| Обзорная карта Монако | Из репозитория ([`public/maps/monaco.pmtiles`](../public/maps/)) | PMTiles, схема Protomaps | Встроена; используется, пока онлайн-карта выключена и нет сохранённых областей |
| Свои карты | Файл `.pmtiles` пользователя | PMTiles | Импорт файлом |

Почему так: OpenFreeMap отдаёт готовые тайлы по обычному HTTP с CORS, поэтому не нужен ни собственный сервер, ни разбор больших файлов; схема OpenMapTiles содержит все категории, нужные слоям; рельеф в открытом доступе есть только отдельным набором, его и берём.

## Как это работает в приложении

1. **Согласие.** Пока пользователь не разрешил онлайн-карту, приложение не делает ни одного внешнего запроса (политика CSP разрешает только два адреса, и то после согласия). Вопрос показывается после знакомства и обучения; включить можно и позже, в *Профиль → Офлайн-карты*.
2. **Автоподгрузка.** MapLibre запрашивает тайлы через собственный протокол `otile://`: сначала кэш (IndexedDB), затем сеть, затем пустой тайл. Отсутствующие на сервере тайлы запоминаются как пустые.
3. **Кэш.** По умолчанию до 500 МБ; когда место кончается, вытесняются самые давние из незакреплённых тайлов. Лимит меняется в настройках, кэш можно очистить.
4. **Сохранённые области.** Тайлы области скачиваются (6 параллельных запросов) и закрепляются: их вытеснение не касается. В офлайне карта берётся из кэша; выше сохранённого масштаба она растягивается.
5. **Предложение при приближении.** Когда вы приближаетесь к незнакомой области, появляется карточка «Сохранить для офлайна» — только при включённой онлайн-карте.
6. **Ограничения.** Одна область — не больше 80 000 тайлов; масштаб карты — до 14, рельеф — до 12.

## Что проверено

* Юнит-тесты (`npm test`): кэш с вытеснением и закреплением, загрузка «кэш → сеть → пусто», отказ без согласия, сохранение и удаление области, отмена, стиль проходит валидацию спецификации MapLibre.
* `npm run test:online`: браузер с подменой серверов — OpenFreeMap отвечает крошечным набором тайлов схемы OpenMapTiles, рельеф — настоящими тайлами AWS (если доступны). Проверено: до согласия нет ни одного внешнего запроса; запросы идут только на два разрешённых адреса; слои метро, отдыха и высот рисуются; область сохраняется; без сети карта рисуется из кэша и приложение не пытается обратиться к серверу; посторонние адреса блокируются CSP.
* **Не проверено:** ответы настоящего OpenFreeMap (формат TileJSON, CORS-заголовки, ограничения на частоту запросов), полнота настоящих данных для слоёв, скорость и размер настоящей области. Массовая загрузка ограничена 80 000 тайлов на область, чтобы не нагружать бесплатный сервис; при необходимости можно поднять собственный экземпляр и указать его адрес.
