# 🧭 TravelOpenMap

**Кроссплатформенный (Android · iOS · веб) дневник путешествий с «туманом войны» на карте OpenStreetMap — целиком офлайн.**

*[English version → README.en.md](README.en.md)*

![Обзор приложения](docs/screenshots/overview-ru.png)

![Что нового в 0.2](docs/screenshots/overview-ru-2.png)

Весь мир скрыт туманом. Вы идёте — туман рассеивается там, где вы побывали. По пути сохраняйте места с фото, видео и описанием, получайте опыт и уровни, проходите челленджи. Карта, шрифты, иконки и код приложения лежат на устройстве: **по умолчанию приложение не отправляет ни одного внешнего запроса** (это не обещание, а проверяемый факт — см. [«Офлайн и приватность»](#-офлайн-и-приватность)); единственное исключение — необязательная, выключенная по умолчанию загрузка карт стран.

## ✨ Возможности

| | |
|---|---|
| 🌫️ **Туман войны** | Карта закрыта туманом; он рассеивается по мере вашего движения по GPS. Радиус открытия настраивается (30–150 м), границы мягкие, с подсветкой. Открытие анимируется. |
| 💨 **Туман с ветром** *(0.2)* | Туман живой: облака дрейфуют по ветру, направление «плавает», скорость меняется порывами. Скорость ветра настраивается или выключается; при неактивности приложения анимация ставится на паузу. |
| 👁️ **Карта без тумана** | Одна кнопка — и туман исчезает, а поверх карты показывается пройденный маршрут. |
| 📍 **Заметки на карте** | Фото, видео, описание, категория (9 штук), точка — ваше место или любое место на карте. Поиск, фильтры, сортировка по расстоянию. |
| 📏 **Измерение расстояний** | Ставьте точки на карте или на заметках — видно суммарную длину, длину последнего отрезка и подписи вдоль линии. Метры/мили. |
| 🧭 **Компас** | Циферблат на датчиках ориентации, стрелка на выбранную заметку с расстоянием, режим «карта следует за компасом». |
| 🏆 **Уровни и челленджи** | 60 уровней и 10 званий (от «Прохожего» до «Хранителя мира»), 38 челленджей (площадь, дистанция, заметки, медиа, серии дней, тренировки, особые), 3 ежедневных задания, серии дней. |
| 📊 **Статистика в графиках** *(0.2)* | *Профиль → Статистика*: столбцы по дням, накопленная площадь, календарь активности, распределения (по часам, дням недели, категориям заметок), диаграмма «исследование/тренировки». Периоды 7/30/90 дней и всё время; у каждого графика есть подсказка по касанию и табличный вид. |
| 🏃 **Тренировки** *(0.2)* | Вкладка «Спорт»: **ходьба и бег** без тумана. Время, дистанция, темп/скорость, сплиты по километру, лучший километр, набор высоты, калории (по MET и вашему весу), маршрут и **площадь**: охваченная полоса вдоль маршрута, площадь петли (если маршрут замкнулся) и выпуклая оболочка. История тренировок, детали, GPX. Защита от скачков GPS. |
| ✈️ **Планировщик поездок** *(0.2)* | *Профиль → Поездки*: страна, города, даты (или «идея» без дат), статус (идея → планирую → куплено → завершена / отменена; «в пути» и «скоро» определяются по датам), чек-лист вещей, бюджет по категориям, лента-таймлайн и обратный отсчёт. |
| 🌍 **Выбор страны для загрузки** *(0.2)* | *Профиль → Офлайн-карты → Добавить страну*: каталог стран с поиском, четыре уровня детализации, оценка размера **до** скачивания. Сама загрузка — необязательная и выключена по умолчанию (см. [«Офлайн и приватность»](#-офлайн-и-приватность)). Добавить карту можно и без сети — файлом `.pmtiles`, с привязкой к стране. |
| 🛡️ **Исключённые зоны** | Задайте круг (дом, работа, что угодно): там туман не рассеивается, шаги не считаются, маршрут не пишется. |
| 🗺️ **Офлайн-карты** | Векторные тайлы OSM в одном файле `.pmtiles`. Встроенная демо-карта + импорт своих файлов или загрузка страны прямо из приложения. |
| 💾 **Ваши данные — у вас** | IndexedDB на устройстве, резервная копия одним файлом, экспорт в GPX и GeoJSON. Ни аккаунтов, ни облака. |
| 🌗 **Тёмная / светлая темы**, 🇷🇺/🇬🇧 интерфейс, метрические/имперские единицы. | |

## 🗺️ OpenStreetMap без интернета — как это устроено

Короткий ответ на вопрос «можно ли выгрузить OpenStreetMap, чтобы приложение никуда не ходило»: **да — по регионам**.

* Целая планета не влезет в телефон: `planet.osm.pbf` — порядка 75 ГБ, готовые векторные тайлы до z15 — больше 100 ГБ. Поэтому приложение работает с **выгрузкой нужного региона** (город, область, страна, маршрут поездки) в формате [PMTiles](https://docs.protomaps.com/pmtiles/) — один файл, из которого MapLibre читает тайлы напрямую с диска, без HTTP-сервера.
* Схема тайлов — [Protomaps Basemaps](https://docs.protomaps.com/basemaps/layers), стиль — официальный пакет `@protomaps/basemaps`. Поэтому подходят **готовые выгрузки Protomaps** (`pmtiles extract`) и любые тайлы той же схемы.
* Шрифты (Noto Sans) и спрайты иконок лежат в `public/map-assets/` (3 МБ) — их скачивает один раз `npm run assets:fonts`.
* Встроена демо-карта **Монако** (0,8 МБ, zoom 0–15). Свои карты добавляются в приложении: *Профиль → Офлайн-карты → Импортировать .pmtiles*.

Три способа получить карту региона (подробно — [docs/OFFLINE_MAPS.md](docs/OFFLINE_MAPS.md)):

1. **`pmtiles extract`** — вырезать bbox из сборки Protomaps (самый быстрый путь).
2. **[`tools/osm2pmtiles.py`](tools/osm2pmtiles.py)** — наш конвертер `.osm.pbf` → `.pmtiles`, для городов и небольших регионов; работает полностью локально. **Проверен на реальных данных:** Монако (0,8 МБ, 11 с), Андорра (горы, без моря; 0,8 МБ, 4 с), Утрехт (каналы, 11 МБ PBF → 4,6 МБ, 83 с). Все три открываются в приложении.
3. **Planetiler** — для стран и континентов.

> ⚠️ Честная оговорка: в среде, где я разрабатывал приложение, серверы OSM (Geofabrik, Overpass, Protomaps) были недоступны, поэтому демо-карта собрана из настоящей OSM-выгрузки Монако из открытого репозитория Project-OSRM. Пути 1 и 3 описаны по документации и **в этой среде не запускались**; путь 2 и импорт файлов проверены полностью.

## 🔒 Офлайн и приватность

Гарантия многоуровневая:

1. **Политика CSP** в [`index.html`](index.html) разрешает соединения только к `self`, `blob:`, `data:` — WebView физически не выпустит запрос наружу.
2. **Внешние ресурсы отсутствуют**: шрифты интерфейса (Inter) — пакетом npm, шрифты и иконки карты — локально, аналитики и CDN нет.
3. **Загрузка карт стран — единственное исключение, и она выключена по умолчанию.** Пока вы не включили переключатель *«Разрешить загрузку карт из сети»* и не указали адрес источника, приложение не делает ни одного запроса, а кнопка «Скачать» недоступна. Когда вы нажимаете «Скачать», приложение на время загрузки создаёт скрытый **изолированный шлюз** ([`gateway.html`](gateway.html), отдельная страница со своей CSP `connect-src http: https:`, без доступа к вашим данным: он получает только адрес и рамку страны и возвращает файл карты). Шлюз читает нужные диапазоны байт (HTTP Range) из PMTiles-источника, [`src/map/extract.ts`](src/map/extract.ts) собирает из них файл выбранной страны, после чего шлюз уничтожается. Основное приложение при этом по-прежнему не имеет права на внешние соединения. Экран **Приватность** показывает, сколько раз за сессию открывался шлюз и к каким хостам.
4. **Android:** разрешение `INTERNET` теперь **есть по умолчанию** (без него шлюз не сможет работать). Если вам нужна строгая гарантия «ОС не даст открыть сокет», соберите приложение с `node scripts/configure-native.mjs --offline-only` — тогда загрузка стран недоступна, а карты добавляются файлом (подробнее в [INSTALLATION.md](INSTALLATION.md)).
5. **Автотест `npm run test:e2e`** запускает *продакшн-сборку* в Chromium с отключённым DNS для всех внешних хостов, «идёт» по улице через эмулированный GPS, создаёт заметку с фото и записывает **каждый** сетевой запрос. Он же проверяет, что по умолчанию шлюз отсутствует в DOM, «Скачать» недоступна, а включение переключателя само по себе ничего не запускает. Результат на момент написания:

```
✅ GPS → туман открывается — 0.01 км² → 0.07 км²
✅ заметка с фото сохранена и видна в списке
✅ экран «Приватность» показывает 0 внешних запросов
✅ по умолчанию сетевой шлюз (iframe) отсутствует; «Скачать карту» недоступна; загрузка выключена
✅ fetch / <img> / WebSocket на внешний сервер блокируются (CSP зафиксировал 3 нарушения)
✅ все запросы приложения — только на локальный origin (25 шт.)
✅ карта, шрифты и спрайты читаются из локальных файлов
```

Отдельно проверена сама загрузка: e2e-сценарий скачал страну из локального PMTiles-сервера (Монако как «источник»): основное приложение сделало 0 внешних запросов, шлюз — 32 Range-запроса к указанному адресу, тайлы собраны в валидный `.pmtiles`.

Экран **Профиль → Приватность** показывает то же самое в самом приложении (счётчик внешних обращений по Resource Timing и обращений шлюза).

## 🎮 Уровни, XP и челленджи

XP считается из статистики (а не копится «руками»), поэтому всегда согласован с данными:

| Источник | XP |
|---|---|
| Открытая карта | 1 XP за каждые 1500 м² |
| Пройденный путь (в т. ч. тренировки) | 1 XP за каждые 50 м |
| Заметка / фото / видео | 25 / 5 / 10 |
| Челлендж / задание дня | 30 … 4000 / 45 … 90 |

Уровень *n* требует `120·(n−1)^1.7` XP (2-й — 120, 5-й — 1 267, 10-й — 5 028, 20-й — 17 909, 50-й — 89 643). Звания: Прохожий → Турист (3) → Путник (5) → Следопыт (8) → Исследователь (12) → Первопроходец (17) → Картограф (23) → Навигатор (30) → Легенда карт (40) → Хранитель мира (50).

Челленджи: **площадь** (0,1 → 100 км²), **дистанция** (1 → 1000 км), **заметки** (1 → 100), **фото/видео**, **серии дней** (3 → 30), **тренировки** (5 новых: первая и десятая тренировки, 5 и 10 км в одном беге, 100 км суммарно), **особые** («Ранняя пташка», «Ночная сова», «Разносторонний», «Марш-бросок 10 км/день»). Ежедневные задания детерминированно зависят от даты.

## 🧱 Технологии и устройство

| Слой | Технология |
|---|---|
| Оболочка | [Capacitor 8](https://capacitorjs.com) (Android, iOS) — один код для всех платформ, работает и как PWA |
| UI | React 19 + TypeScript + Vite, собственная дизайн-система (CSS-переменные, стекло, тёмная/светлая темы) |
| Карта | MapLibre GL JS 6 + PMTiles + стиль `@protomaps/basemaps` |
| Туман | Сетка ячеек Web Mercator z20 (≈27 м в Монако) + Canvas-рендерер: маска низкого разрешения, кисти, пороговая кривая, свечение границы |
| Данные | IndexedDB v2 (`idb`): заметки, медиа, чанки тумана, дни, треки, карты, тренировки, поездки |
| Состояние | Zustand |
| Датчики | Geolocation (Capacitor), DeviceOrientation (компас), Haptics |
| Графики | Собственные SVG-компоненты ([`src/ui/charts.tsx`](src/ui/charts.tsx)): цвета из токенов темы, подсказки, табличный вид |
| Тесты | Vitest (67 тестов), Playwright (e2e-проверка офлайна, скриншоты) |

**Ветер.** Отрисовка тумана разделена на `rebuild()` (дорогая маска — только когда изменились карта или открытые ячейки) и `composite()` (дешёвая композиция облаков поверх маски, ≤30 кадров/с). Облака — многооктавный fBm-шум с квинтической интерполяцией, смещаемый в мировых координатах; два слоя облаков дрейфуют в разные стороны; порывы меняют скорость, направление «плавает». При сворачивании приложения анимация останавливается, чтобы не тратить батарею.

**Тренировка** ([`src/core/workout.ts`](src/core/workout.ts), [`src/state/workoutEngine.ts`](src/state/workoutEngine.ts)) — отдельный движок, никак не связанный с туманом: во время тренировки туман скрыт, исследование карты не засчитывается. Дистанция и темп считаются по фиксам GPS с фильтром точности и антисбоем: скачки отбрасываются, а после трёх подряд «далёких» фиксов якорь переносится (иначе после потери сигнала маршрут навсегда «залипал» бы на старой точке). Площадь — три оценки: полоса вдоль маршрута (≈50 м), площадь петли (полигон маршрута, если он замкнулся) и выпуклая оболочка.

Почему туман — это сетка ячеек, а не «полигон с дырками»: объединять сотни тысяч пересекающихся кругов в полигон дорого, а ячейки дают O(1) на проверку/добавление, простую сериализацию по чанкам 64×64 и точную статистику площади. На 340 тыс. ячеек (261 км² пройденного) отрисовка занимает 2–8 мс на кадр (замерено, headless Chromium с программным рендерингом).

## ⚠️ Что проверено, а что нет

Проверено автоматически в этой среде: юнит-тесты (67), типы, продакшн-сборка, весь пользовательский путь в Chromium (GPS-эмуляция, заметки с фото, измерение, зоны, импорт `.pmtiles`, тёмная/светлая темы, ru/en), отсутствие внешних запросов (в том числе то, что шлюз загрузки по умолчанию неактивен), загрузка страны с локального PMTiles-сервера, производительность тумана, все новые экраны в тёмной/светлой темах и ru/en (скриншоты).

**Не проверялось** (нет Android SDK / Xcode / устройств): сборка и запуск нативных приложений, реальные датчики компаса и GPS, запись видео с камеры телефона, поведение WebView с custom-схемой на iOS. Нативные проекты сгенерированы Capacitor и настроены скриптом, но на реальном устройстве их ещё предстоит проверить — см. раздел «Решение проблем» в INSTALLATION.md.

**Не проверялось дополнительно для 0.2:** загрузка с реального сервера Protomaps (в среде разработки он недоступен) — источник должен поддерживать HTTP Range и отдавать CORS-заголовки (`Access-Control-Allow-Origin`, `Access-Control-Expose-Headers: Content-Range`); если нет — шлюз покажет ошибку, а карту можно добавить файлом. Тренировки, как и туман, записываются только пока приложение на экране; качество площади/калорий зависит от точности GPS (калории — оценка по MET, не медицинский показатель). Размер загрузки показывается как **оценка** (число тайлов известно точно, байты — по эвристике плотности), а загрузка ограничена 300 МБ в памяти.

**Известные ограничения**

* Туман и тренировки записываются, только пока приложение на экране (фоновое отслеживание GPS не реализовано — это следующий шаг, плагин `@capacitor-community/background-geolocation`).
* Один активный файл карты одновременно; для длинных поездок делайте карту-объединение нужных регионов.
* Метки на карте в PMTiles-выгрузке нашего конвертера — подмножество схемы Protomaps (нет `landcover`, `transit`, дорожных щитов); у выгрузок `pmtiles extract` этого ограничения нет.
* Шрифты карты включают латиницу, кириллицу, греческий; для CJK/арабского нужны дополнительные диапазоны глифов.
* Полная резервная копия с видео хранится как base64 внутри JSON — для очень больших коллекций она тяжёлая.
